# Jig Brand Assets

This directory contains Jig brand assets for use in documentation and social previews.

## Files

- `icon.png` — Jig pictogram: cluster of dark terminal cards with coral border on the front one
- `social-preview.png` — GitHub Open Graph / social preview lockup: cluster LEFT, "Jig" wordmark in open grotesk coral, tagline "terminals on a canvas", light paper background
- `lockup.png` — Centered icon + Jig wordmark + tagline

## Usage

- Use `social-preview.png` as the README hero image
- Set `social-preview.png` as the GitHub repository social preview in Settings → Social preview
- `icon.png` can be used inline in documentation
- `lockup.png` is optional for centered lockup compositions

## Guidelines

- Do not modify the design, crop taglines, or regenerate these assets
- Keep images optimized for web use
- Maintain the original aspect ratios and composition
